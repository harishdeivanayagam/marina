The Standard Library

Everything marina programs can call without installing a package: a handful of built-in globals, five use-able std modules, and the methods every array and string carries.

Overview

Two kinds of library ship with the language:

  • Built-in globals — console, setTimeout and Promise are always available, no import needed.
  • Std modules — net, http, fs, crypto and sql are brought in with a top-level use statement (the JS-style import is not supported):
use http
use crypto

Every std function has a synchronous form and an async form that returns a promise — fs.readFile(path) blocks, await fs.readFile(path) runs on the event loop's worker pool. Blocking I/O errors panic with the operation and OS error text.

Built-in globals

GlobalSignatureDescription
console.loglog(value)Prints the value's string form plus a newline. The only console member.
setTimeoutsetTimeout(fn, ms)Runs fn on a worker thread after ms milliseconds (negative values are treated as 0).
Promisenew Promise((resolve, reject) => { ... })Creates a promise; the executor runs synchronously (JS semantics). await the promise to resume after resolve(value).
console.log("hello")

setTimeout(() => {
    console.log("2 seconds later")
}, 2000)

let p = new Promise((resolve, reject) => {
    resolve(42)
})
console.log(await p)  // 42

net — raw TCP

net.connect(host, port) opens a TCP connection and returns a Stream. Streams have three methods:

MethodDescription
stream.write(data)Send bytes (a string) over the connection.
stream.read_all()Read until EOF and return the payload as a string (30s read timeout).
stream.close()Close the stream. Unclosed streams are closed when the process exits.

All four operations (connect included) have async variants. I/O errors panic.

use net

async function main() {
    let stream = await net.connect("example.com", 80)
    await stream.write("GET / HTTP/1.1\r\nHost: example.com\r\n\r\n")
    console.log(await stream.read_all())
    await stream.close()
}

http — client & server

The http module has a small client, a low-level server, and an express-style layer on top.

Client

FunctionDescription
http.get(url)HTTP GET; resolves to an http.Response object { status, body }.
http.post(url, body)HTTP POST with a string body; same response shape.
let res = await http.get("https://api.example.com/v1/ping")
console.log(res.status)  // 200
console.log(res.body)

Low-level server

http.listen(port, handler) binds 0.0.0.0:port and serves requests sequentially; the handler receives (req, res) and must be a lambda. res.send(value) replies with plain text, res.json(value) serializes arrays, objects, strings and numbers.

Express-style server

MemberDescription
new http.Server()Create a server. Takes no arguments.
server.router({ path: "/x" })Bind a router to a path prefix and register routes with router.get(path, handler) / router.post(path, handler).
await server.listen(host, port)Bind and start the poll(2)-multiplexed event loop — many concurrent connections.
req.bodyThe raw request body string on http.Request.
http.JsonValidatorValidate JSON bodies: http.JsonValidator.string() / .number() create field validators, chainable with .required(), .min(n), .max(n); validator.validate(body) returns a checked object.

fs — filesystem

FunctionDescription
fs.args()Process arguments (everything after the script name) as Array<String>.
fs.readFile(path)Read a whole file into a string.
fs.writeFile(path, data)Write a string to a file.
fs.exists(path)Does the path exist?
fs.readDir(path)Directory entry names, sorted.
fs.mkdir(path)Create a directory (recursive).
fs.remove(path)Remove a file or directory (recursive for dirs).

Every function except args also has an async variant. Errors panic with fs.<op> '<path>': <os error>.

use fs

async function main() {
    await fs.writeFile("notes.txt", "hello")
    console.log(await fs.readFile("notes.txt"))
    for (let name in await fs.readDir(".")) {
        console.log(name)
    }
}

crypto — hashing & encoding

Pure C++ implementations — no OpenSSL dependency:

FunctionDescription
crypto.sha256(data)Lowercase hex SHA-256 digest.
crypto.base64Encode(data)Base64-encode a string.
crypto.base64Decode(data)Base64-decode; skips = padding and whitespace, yields lossy UTF-8.
crypto.randomHex(numBytes)Cryptographically random bytes from /dev/urandom as lowercase hex (clamped to 0–4096 bytes).
crypto.uuid()Random UUID v4.
use crypto

console.log(crypto.sha256("marina"))
console.log(crypto.base64Encode("marina"))
console.log(crypto.uuid())

sql — SQLite

SQLite via the system libsqlite3 (MySQL/Postgres drivers are not available yet). Values are always bound as prepared-statement parameters — never string-concatenated — through the sql.stmt tagged template: ${expr} binds a value; only integers, floats, strings and bools can be bound.

MemberDescription
new sql.Connection(driver, url)Open a connection; only "sqlite" is supported.
db.execute(stmt)Run a statement that returns no rows; resolves to { lastInsertId, changes }.
db.query(stmt)Collect rows as objects whose fields are the column names (Array<Row>).
db.close()Close the connection.
use sql

async function main() {
    let db = new sql.Connection("sqlite", "app.db")
    await db.execute(sql.stmt`CREATE TABLE IF NOT EXISTS t (id INTEGER PRIMARY KEY, name TEXT)`)
    let result = await db.execute(sql.stmt`INSERT INTO t (name) VALUES (${"marina"})`)
    console.log(result.lastInsertId)
    let rows = await db.query(sql.stmt`SELECT id, name FROM t`)
    console.log(rows)
}

Array methods

Every array value carries these members (callbacks run synchronously):

MemberDescription
lengthNumber of elements.
push(v) / unshift(v)Append / prepend a value; returns the new length.
pop() / shift()Remove and return the last / first element (panics on empty).
splice(start, count)Remove count elements at start (clamped); returns them as a new array.
slice(start, end)Copy elements [start, end) (clamped) into a new array.
concat(other)New array with the elements of both arrays.
join(sep)Join the elements' string forms with a separator.
reverse() / sort()In place; returns the same array. sort is stable — numbers numerically, strings bytewise.
forEach(item => Void)Run a callback for each element.
map(item => T)New array of the callback results.
filter(item => bool)New array of elements whose callback returned true.
reduce((acc, item) => T, init)Fold the array into a single value.

Indexing (arr[i]) is bounds-checked and panics when out of range.

String members

Strings are UTF-8 byte sequences; indices are byte offsets:

MemberDescription
lengthLength in bytes.
charAt(index)Byte (code unit) at index, 0 when out of bounds.
substring(start, end)Substring over byte indices [start, end), clamped; an end below start yields "".

String equality (==/!=) compares content, and any value can be interpolated into template literals: `hello ${name}`. console.log formats any value via its string form.
