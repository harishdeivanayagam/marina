// what it is

compile
Lex, parse, type-check, LLVM IR, then clang. A static executable. No VM, no JIT warmup.
types
No any. Parameters must be annotated. Integers are Int8–Int64 and UInt8–UInt64 (default Int32); floats are Float32 and Float64 (default Float64). An integer widens to a float, and Float32 widens to Float64. Generics are monomorphized.
memory
Automatic reference counting. The compiler inserts retain and release. Interned string literals are immortal.
async
async/await lowers to promise state machines, resumed on a worker pool. Servers run on poll(2).
wave
init, add, check, build, run. Packages live in one global registry, not a node_modules tree.
std
net, http, fs, crypto, sql (SQLite), including an express-style server.

// hello-world.tsm

Files are .tsm, kebab-case. wave run compiles and runs.

hello-world.tsm
async function main() {
    let name = "marina"
    let todos = ["ship v0.2", "write docs"]

    const MSG = `Hello from ${name}, ${todos.length} todos`
    console.log(MSG)
}
