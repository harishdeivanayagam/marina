Benchmarks

Workload: the todos REST API (HTTP + SQLite) — examples/todos-http-sqlite.tsm — with the identical API implemented for Node.js, Bun and Go. Load generated with wrk on loopback on a Vultr vc2-1c-1gb instance (1 vCPU Xeon Cascadelake, Ubuntu 24.04). Marina v0.2.0 evented build, AOT binary 2.5 MB. Benchmarked 2026-10-19.

Per runtime: fresh SQLite DB (10 seeded rows) → 10 s warmup → 30 s wrk -t4 -c64 GET → 20 s wrk -t4 -c64 POST. RSS sampled every 50–100 ms.

Takeaways

Bun wins raw GET throughput (~19.9k req/s), but the evented Marina build sits in the same league as Go and Node — 11.1k req/s at c=64 with a tighter p99 than both, and 1,400 POST req/s (write + validation), beating Bun and Node on writes.

The headline is memory: Marina's AOT binary idles at 4.2 MB and peaks at 7.1 MB — a third of Go's peak, and roughly 12× lighter than Node.js.
